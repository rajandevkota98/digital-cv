4Projects

Ref. A

omni-assistant

Voice assistant model for the Linux desktop

GitHub Hugging Face Colab

  • Built a speech-in, tool-calling assistant model that hears audio directly with no separate speech-to-text step, connecting a frozen Whisper-small encoder to Qwen3-0.6B through a LLaVA-style audio adapter (8.4M parameters).
  • Designed the data pipeline: 20K synthetic desktop commands, cleaned and deduplicated into stratified splits with a frozen test set, multi-turn samples for confirmations, tool results, and errors, voiced with 8 TTS voices plus noise, with separate voices held out for testing.
  • Trained in three stages on Modal GPUs: typed tool SFT with QLoRA (NF4, r=32), audio alignment (7.0% WER on LibriSpeech test-clean), and joint spoken SFT with replay, raising spoken tool-call accuracy from 17.5% to 72.1%.
  • Found that merging the LoRA into the dequantized 4-bit base, rather than the original bf16 weights, recovered 1.3 points on noisy audio; chose bf16 serving (0.3–1.4 s per turn on an L4) after measuring int8 at about 4× slower.
  • Shipped a working desktop voice agent that runs real actions (apps, URLs, volume, timers, weather) through an allow-listed executor with no shell access, asks before risky actions, and speaks replies with Kokoro-82M.
  • Published the model with a model card that reports evals honestly, including the targets it missed.

PyTorch · Transformers · PEFT/QLoRA · bitsandbytes · Whisper · Qwen3 · Kokoro TTS · Modal · Hugging Face Hub

Production OCR Platform

Two-stage document understanding on Modal

GitHub

  • PP-DocLayoutV3 (ONNX) segments pages into text, table, formula, and figure regions, and Qwen2-VL-2B (bf16 on A10G) transcribes each crop with region-specific prompts into Markdown tables and LaTeX formulas.

  • Built an evaluation harness (CER, WER, Kendall’s τ reading order, table-structure and formula-term scoring) on a 100-page synthetic benchmark; against a RapidOCR baseline, raised multi-column reading-order τ from 0.486 to 0.734 and formula-term recall from 77.6% to 92.0%.
